# 2026-10-29 안정성 개선

기존 작업본과 최신 main을 통합한 뒤, 실제 사용에 영향을 주는 데이터 보존·입력·이동·조회 문제를 단계별로 수정했습니다. 검증에는 별도 로컬 DB와 합성 자료를 사용했습니다.

## 데이터 보존

- `listing_source_notes`에 원문과 최소 업무 연결 정보를 보존합니다. 마지막 상태 이벤트가 없어져도 원문이 사라지지 않으며, 주소 정정이 다른 집으로 원문을 자동 복사하지 않습니다.
- 삭제는 해당 원문을 현재 자료에서 제외하고 휴지통에 보관합니다. 일부 복구와 단일·일괄 영구 삭제 후 다른 업무 복구에서도 삭제한 문장이 되살아나지 않도록 실제 업무 존재 여부를 같은 원자적 guard에서 확인합니다.
- 원문이 없던 새 매물은 불필요한 보관 자료를 만들지 않습니다. 빈 삭제 표식은 유지하고 원문 연결 정보는 JSON 배열로 제한합니다.
- schema·bootstrap 4·migration 0007·백업·과거 v1 복구 검사를 동기화했습니다.
- 주소 식별자를 충돌시키는 `|`는 주소 필드에서 거절합니다. 메모와 물건지 문자는 제한하지 않습니다.

검사: `listing-source-storage`, `listing-history-consistency`, `deletion-safety`, `backup-recovery`, `runtime-performance` 테스트.

## 수정·인증 경계

- 할 일 수정·완료·미루기는 조회 시 받은 SHA-256 revision과 저장 시 실제 값을 함께 검사합니다. 같은 초의 수정과 읽기/쓰기 사이의 경합도 기존 내용을 덮지 못합니다.
- 충돌 후 목록을 갱신하고, 편집 중인 초안은 유지하면서 최신 저장 내용을 별도로 확인합니다. 최신 내용으로 다시 열기는 초안 취소를 확인합니다.
- 고객ID·매물키는 실제 라우터의 한 번 디코딩 계약을 따릅니다. `%`, `%32`, `/`, `?`, `#`를 포함한 합성 식별자의 조회·수정·삭제를 검사합니다.
- 차단 중 로그인 재시도가 원래 만료를 미루지 않습니다. 정확한 만료·만료 직후·정상 암호·반복 실패를 검증합니다. 로그아웃과 암호 변경의 서버 세션 무효화도 유지합니다.

검사: `followups`, `followup-workflow-ui`, `route-params`, `auth-session` 테스트.

## 화면·조회

- 한국어 조합 중 Enter·229 이벤트로 고객을 확정하거나 모달을 닫지 않습니다.
- 고객·매물 이력은 browser back/forward에서 대상을 다시 읽어 복원합니다. 저장 중 이동·오래된 응답 방어는 유지합니다.
- 통합검색의 최대 8개를 명시하고 같은 검색어의 전체 목록으로 이어집니다.
- 관리 목록은 먼저 100건을 표시하고 더보기로 이어집니다. CSV는 같은 조건의 전체 결과를 별도로 수집하며 중간 실패 시 일부 파일을 저장하지 않습니다.
- 고객 이력은 직접 연결/물건지 연결의 후보 ID를 UNION으로 구하고 source 식 인덱스를 사용합니다. 검색·필터·정렬·중복 제거 결과를 이전 쿼리와 비교합니다.

검사: `customer-picker-usability`, `managed-navigation-improvements`, `query-performance`, `customer-directory-consistency`, 관련 화면 회귀 테스트.

## 검증 범위

최종 로컬 검증(Node.js 26): lint, 타입 검사, 배포 빌드와 **563개 테스트 전부 통과**. Drizzle migration 검사와 diff 검사도 통과했습니다. 브라우저에서는 가상 고객 205명의 100→200→205 표시, 전체 205명 및 필터 201명 CSV의 ID·행 수·정렬을 확인했습니다. 320px 큰 글씨에서도 검색 버튼 44×44px을 확보했고 글자 크기를 유지했습니다. 이 QA의 API 52건에서 오류 응답과 콘솔 오류·경고는 없었습니다.

각 단계의 실제 SQLite·API·화면 콜백 검사에 이어 lint·타입·배포 빌드·전체 Node 회귀 테스트를 실행합니다. 브라우저에서는 가상 계정으로 한국어 이벤트, 새 업무·고객·할 일 흐름, 이력 복원, 205명 목록과 CSV, 모바일 큰 글씨를 확인합니다. 최종 자동 검사 결과는 [CI](https://github.com/seopseopi/jipjangbu/actions/workflows/ci.yml)에서 확인할 수 있습니다.
