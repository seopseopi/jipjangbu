# 집 구조 보기 — TEST 구현 현황

2026-09-17. 아키텍처 문서 이후 추가한 **첫 테스트 가능 버전**이다. 사이드바의 **집 구조 보기 · TEST**로 제공한다. 운영 배포 시 신규 구조 테이블만 추가하며 로컬 예시 데이터는 이관하지 않는다.

## 실행과 확인

`npm run dev -- --port 5174` 후 `http://localhost:5174/#structures`에 접속한다. 기존 관리자 로그인을 유지한다. 로컬 D1/R2와 운영 DB는 별개다. 로컬에 보이는 예시 고객·업무는 운영 데이터가 아니다.

1. 왼쪽 **집 구조 보기**를 누르면 실제 매물·세대 목록이 먼저 열린다. **참고 도면 예제**에서 검단힐스테이트 109㎡ 기본형의 재구성 화면과 외부 KB 원본을 대조할 수 있다. 가상 예제는 **가상 구조 체험**으로 별도 제공한다.
2. 2D/3D 전환, 방 선택, 확대/축소/초기화, 3D 회전, 반전된 체험 B를 확인한다.
3. 실제 매물로 돌아가 단지 → 동 → 기록된 호수를 고르면 현재 매물 정보와 방문·상담을 포함한 기존 업무를 읽을 수 있다. 기록을 누르면 기존 업무 내용 모달이 열린다.
4. 매물 이력의 **집 구조 보기** 버튼으로도 진입한다.
5. **도면 관리**에서 근거 있는 구조 JSON을 검증·새 버전으로 등록하고, 확인된 세대에 연결할 수 있다. 데모 JSON은 실단지 등록을 서버에서도 차단한다.

## 구현된 범위

- SVG/R3F 공통 JSON, 방 라벨/선택, 문·창 실제 개구부, 좌우반전/회전, lazy 3D 및 자원 정리.
- 입구가 확인된 참고 도면에는 도면 안의 출입구 표시와 켜고 끌 수 있는 안내선을 제공한다. 별도 입구 설명 영역과 현관 찾기 버튼은 제거했다. 3D는 도면에 설정된 원래 벽 높이를 유지하며 위에서 보기를 선택할 수 있다. 안내선은 배치 설명용이고 피난 경로가 아니다. 참고 도면의 타일·바닥 색, 욕실·주방 설비는 2D/3D에서 동일한 위치 데이터를 사용한다. 방 이름은 두 뷰에서 켜고 끌 수 있다.
- 모바일 구조/기록 탭, 로딩·오류·자료 미확인 안내, WebGL 오류 시 평면도 fallback.
- 기존 매물·업무 데이터 조회 API 재사용. 매물 상태 이벤트가 없는 방문 기록도 탐색.
- 로컬 D1의 단지/동/세대/타입/불변 도면 버전/세대 연결/CRM 키 연결/감사 기록.
- JSON·파일 등록 검증, 단지·타입·동호수 선택 연결, 명시적 버전 변경, 동시 수정 충돌 방지. 별도 근거 입력·승인 화면은 두지 않는다.
- 신규 테이블을 기존 암호화 백업에 포함. 백업 목록/만료 정리에서 도면 등 다른 prefix 제외.
- Drizzle 추가 마이그레이션과 bootstrap 열 구성을 일치시킨 테스트.

## 설계 대비 남은 범위 — 정식 기능 전환 전 필요

- **KB 검단힐스테이트 109㎡ 기본형 원본을 열어 확인하고 배치를 수작업 재구성**했다. `hillstate-reference.ts`에 출처/확인일/시각화 가정을 기록했다. 침실 3·욕실 2·드레스룸·발코니의 위치와 꺾인 외곽을 따르되 벽 높이/두께, 문창 상세는 미검증이다. 원본은 외부 호스트에서 표시하며 이미지 사본을 GitHub에 올리지 않는다. 재배포 권한·동호수 타입 배정은 미확인이다. `referenceOnly`로 일반 도면 등록을 차단하고 어떤 실세대에도 연결하지 않았다.
- 2026-10-30부터 PDF·JPG·PNG 원본을 32MiB까지 R2에 등록하고 JSON 없이 2D로 열람한다. PDF 페이지 이동·확대·회전, 원본 다운로드를 지원한다. 구조 JSON 도면의 2D·3D 경로도 유지한다. 파일 포함 백업 다운로드와 격리 복구를 검증했다. 배치도 hotspot·OCR·PDF의 자동 3D 변환은 미구현이다.
- 확인된 세대는 목록에 표시하지만 전체 층·호수 행렬, 영구 deep link/선택 복원, 공식 단지 별칭 관리, 연결 해제·보관/철회 관리, 대규모 업무 cursor pagination은 아직 미구현이다.
- 물리 세대 연결은 `structure_listing_links.identity_key`로 보존한다. 재생성될 수 있는 `listings.id` 포인터는 초기 버전에 두지 않았다. 가격/상태/업무 본문을 구조 테이블에 복제하지 않는다.
- 실자료 대조, 치수 정합성, 복잡한 다각형/벽 교차부 검증, 실제 모바일 성능 인수 뒤 정식 기능 전환 여부를 별도로 결정한다.

구현된 것과 설계 전체의 완료를 구분한다. TEST 기능이며, 검증하지 않은 실세대 구조를 제공하는 서비스로 안내하지 않는다. 확대는 회전·이동한 시점을 유지하며, 보기 초기화는 시점·배율·선택·방 이름·안내선을 기본값으로 되돌린다.

## 2026-10-30 파일 도면 등록

**도면 관리 → 도면 등록**에서 PDF/JPG/PNG를 선택하고 원본을 미리 확인한다. 단지·타입을 선택해 등록한 뒤, **세대 연결**에서 확인한 동·호수에 해당 버전을 연결한다. 기존 단지를 선택하면 공식 이름과 주소를 다시 입력하지 않는다. 새 버전을 등록해도 기존 세대는 이전 버전을 유지하며, 관리에서 명시적으로 선택해야 변경된다.

같은 이름의 단지는 공식 ID와 주소로 구분한다. 아직 연결하지 않은 장부 별칭은 별도 목록에 표시하며 이름·면적만으로 같은 단지로 추정하지 않는다. 원본은 인증된 API로만 제공하고, 파일 크기·서명·SHA-256을 확인한다. DB 저장 실패 시 새 업로드를 정리한다.

백업 스냅샷은 불변 파일 참조를 보관하고, 설정에서 **백업 내려받기**를 하면 원본 파일 바이트까지 포함한 JSON을 받는다. `node --experimental-strip-types scripts/check-backup.mjs <파일>`로 도면 SHA-256 및 격리 DB의 연결을 검증할 수 있다. 오래된 DB 전용 백업의 파일 미포함 상태를 복구 성공으로 안내하지 않는다. 원본 파일은 백업 만료 정리 대상에서 제외하며 현재 자동 삭제하지 않는다.

실제 22,141,880바이트·12쪽 PDF와 PNG 등록/연결/조회, 모바일 320·390px, 원본 포함 백업의 해시 일치, 로컬 격리 복구를 확인했다. 운영 도면이나 실세대 정보를 테스트 대상으로 사용하지 않았다. 외부 도면 API의 계약·키·실단지 수록률은 이 구현으로 확보한 것이 아니다.

## 2026-10-30 화면 단순화

기본 화면에는 도면과 2D·3D 전환만 표시한다. 원본·편집과 업무 기록은 접어서 둔다. 관리 작업은 세대 연결 / 도면 등록 / 도면 편집 선택 메뉴 하나로 통합한다. 확인 근거·사용 허락 근거·가공 메모 입력과 확인 체크박스, 별도 상담 모드·승인 절차는 없다. 장부 물건의 동·호수는 고정되며 API에서도 다른 동호수로의 첫 연결을 차단한다.
