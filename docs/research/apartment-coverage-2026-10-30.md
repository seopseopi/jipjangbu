# 관리 아파트 평면도 수집·가공 현황

2026-10-30 KST. 운영 DB 읽기 전용 확인 + Exa 검색 + 공개 KB 단지 페이지의 타입별 데이터 직접 대조.

## 확보 범위

- 관리 목록: 장부명 30개. 운영의 단지·타입·세대 구조 테이블은 아직 비어 있었다.
- 25개 장부명에 대응하는 공개 타입 정보 96개를 수집했다. 나머지 5개도 단지 출처를 확보했으나 원본 도면은 수집 대기다.
- 기본형 원본 82개, 확장형 10개 URL을 찾았다. 실제 GET 검사에서 89개가 HTTP 200 및 이미지 MIME을 반환했고, 힐스테이트4차 기본형 3개는 404여서 제품 데이터에서 제외했다. 현재 기본형 79개, 확장형 10개다. URL 가용성은 검사 시점 기준이다.
- 공개 이미지 자체를 Git에 복사하지 않았다. 인증된 사용자가 고정된 출처 목록의 원본을 열고, 필요하면 내부 파일로 등록·가공할 수 있다.
- 수집 자료는 장부명에 대응하는 **단지·타입 후보**다. 주소가 없는 장부를 공식 단지로 확정하거나, 공급면적만으로 특정 호수·방향·확장 상태를 확정하지 않는다.
- 3D는 모든 타입에 완성된 상태가 아니다. 기존 검단힐스테이트 109㎡ 재구성 1개는 대조 전 참고 자료이고, 등록 원본에 대해서는 외곽·방 경계를 추적하여 새 2D·3D 모델을 저장하는 편집 기능을 추가했다.

## 오류·충돌 확인

- `금호어울림`: 운영 장부의 101~106동·32평은 검단금호어울림(마전동 1030-1) 후보와 맞는다. 원당 금호어울림·마전금호어울림(901~903동)·검단금호센트럴을 같은 단지로 병합하지 않았다.
- `미래지향`: 운영 장부에 201동이 있다. 공식 현황은 검단로511번길24 이지2차미래지향1단지의 201동을 명시한다. 검단로501번안길5 이지미래지향(101~103동)의 도면을 201동 후보에 제시하지 않는다. 해당 원본 추가 수집이 필요하다.
- `유호`: 공식 현황상 A/B/C/D가 서로 다른 주소다. 단일 단지·타입으로 일괄 연결할 수 없다.
- `동아`: 현업 중개사의 공개 자료에 기존 포털 평면도와 실제 구조가 다르다는 지적이 있어 원본 대조를 요구한다.
- `힐스테이트1차`: 장부에 51A 같은 공개 타입과 일치하지 않는 표기가 일부 있어 후보 없음으로 표시한다. 장부를 자동 수정하지 않았다.

## 추가 제작·확인이 남은 것

1. 금호어울림·우림필유·드림파크어울림1단지·유호·우방3차의 타입별 원본과 미래지향201동 원본 확보.
2. 힐스테이트4차 삭제된 원본 재수집, 기본형 없는 타입의 대체 공식 자료 수집.
3. 각 도면의 평면도 영역 분리, 방·벽·문·창 좌표와 치수의 대조 및 3D 제작.
4. 공식 동호수 배치 자료를 기준으로 세대별 타입을 연결하고 실제 확장·방향을 확인.
