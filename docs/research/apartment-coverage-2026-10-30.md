# 관리 아파트 평면도·동별 타입 수집 현황

2026-10-30 KST. 운영 장부 읽기 전용 점검, 공개 KB 단지 페이지·공개 동별 타입 조회, 공식 아파트 현황 대조.

## 이번 추가 조사 결과

- 관리명 30개 모두 타입 자료 확보. 검토한 제품 데이터는 122개 타입, 이미지가 있는 타입은 108개다.
- 기본형 98개·확장형 24개, 총 122개 이미지 URL. 이번 새로 확보한 이미지 URL 37개는 모두 GET 200 및 이미지 MIME을 확인했다. 기존 힐스테이트4차 기본형 3개 404는 계속 제외했다.
- 29개 관리명에서 239개 동의 타입 목록을 확보했다. 단지명이나 평수만 비교하던 후보 선택을 동별 타입 ID로 제한했다.
- 기존 미확보 5개 관리명(금호어울림·우림필유·드림파크어울림1단지·유호·우방3차)의 타입·일부 원본을 찾았다.
- 미래지향은 기존 101~103동 자료를 제거하고 실제 장부의 201동 자료로 교체했다. 공개 KB가 1·2단지 정보를 묶으므로 301·302동의 공급 110.74㎡ 78세대는 제외했다. 원자료에는 123개 타입이 있었고, 다른 단지 1개 타입 제외 후 122개다.

## 장부 대조

- 아파트 기록 336건 중 234건은 공개 동별 목록이 단일 타입이고 장부 평형 후보와 일치했다.
- 83건은 여러 타입이 있는 동에서 장부 평형·접미사와 한 후보가 일치했다. 호수별 라인 배정은 확인 전이다.
- 3건은 후보가 여러 개, 14건은 장부 표기와 후보 불일치, 2건은 동 목록 미확보다. 불일치에는 면적 표기 관행 차이도 있으므로 장부 오류로 단정하지 않는다.
- 종료일 없는 38건: 동 전체 단일 타입 일치 25건, 동별 복수 타입 중 장부 후보 일치 12건, 공개 동별 목록과 장부 표기 충돌 1건.
- 충돌 1건은 아이파크1차 107동 기록의 33평 표기다. 공개 동별 자료는 해당 동을 94.26㎡(통상 28평형)로 분류한다. 특정 호수의 실제 구조까지 확인한 결과는 아니다.
- 평수는 장부의 버림/반올림 두 관행을 후보 검색에 허용한다. 후보가 맞는 것과 세대 타입이 확정된 것은 다르다.

**운영 매물→도면 확정 연결 0건, 운영 실제 세대 3D 등록 0건이라는 직전 확인 결과는 달라지지 않았다. 이번 변경은 자료 확충과 후보 오연결 방지다.**

## 아직 필요한 자료

- 14개 타입에 원본 이미지가 없다: 영진 5개, 유호 7개, 아이파크2차 1개, 마전동남 1개.
- 힐스테이트4차·모아미래도·양우내안에는 확장형만 확보한 타입이 있다. 기본형을 임의로 확장형과 같다고 취급하지 않는다.
- 미래지향 201동의 호수별 타입·라인, 유호의 장부 B동 약칭과 B1/B2 구분을 추가 대조해야 한다.
- 동아의 포털 도면과 실제 구조 차이 지적은 해소되지 않았다.
- 혼합 타입 동의 호수별 배정, 좌우 반전, 실제 확장·리모델링 상태는 확인 전이다.
- 고객용 크롭·정리와 타입별 2D·3D 제작은 별도 작업이다. 실제 치수·문·창을 추정해 완료 처리하지 않는다.
- KB의 호수별 조회는 사용자 인증 오류를 반환해 사용하지 않았다. 네이버 도면 갤러리는 403을 반환했다. 인증·차단 우회는 하지 않았다. 공개 분양 원본, 지자체 현황, 현업 자료를 교차 조회했다.

## 재현 가능한 수집 경로

- 단지 목록: `https://api.kbland.kr/land-complex/complexComm/hscmList?법정동코드=2829010300`
- 동 목록: `https://api.kbland.kr/land-complex/complexComm/dongList?단지기본일련번호=<공개 단지 ID>`
- 동별 타입: `https://api.kbland.kr/land-complex/complexComm/dongTypeList?단지기본일련번호=<ID>&동일련번호=<반환된 동 ID>`
- `app/structures/apartment-building-types.json`은 각 동의 출처 URL과 타입 ID를 보관한다. API는 공개 읽기 전용 데이터만 사용했다.
- `scripts/research/collect-kb-plans.py`, `scripts/research/collect-kb-building-types.py`는 무검토 제품 덮어쓰기를 하지 않고 ignored `output/research`에 후보만 출력한다.
